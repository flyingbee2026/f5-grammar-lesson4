# F5 Grammar Lesson 4 — Cleft sentences

Handouts in Helen's Lesson 3 format: header block → Part 1 proofreading quiz → Part 2 warm-up →
Part 3 patterns in formal writing → Part 4 practice sets → Part 5 writing task.

- `Lesson 4 - Cleft sentences (Teacher's).docx` — teacher handout (answers inline) — 7 pages
- `Lesson 4 - Cleft sentences (Student's).docx` — student handout (derived from the teacher file) — 6 pages
- both PDFs, plus `F5 Grammar Lesson 4 - Cleft sentences.zip` (4 handout files)
- `build_lesson4.py` (teacher) and `build_student.py` (derives the student copy from the teacher docx)
- `qa_lesson4.py` — structure, dedupe, sample word-count, set/answer checks, PDF page checks
  (`python3 qa_lesson4.py teacher|student`)

Content: Part 1 tests noun/adjective word-form confusion + inversion (Not only / Only by / Never);
Part 2 is a 20-item cleft gap-fill (it / is / was / that / who / what / until / when); Part 3 gives four
Plain → More formal cleft conversions plus "Clefts as paragraph openers"; Part 4 has eight practice
sets (4–8 harder); Part 5 is an ~80-word online-bullying paragraph with three sample answers
(one it-cleft, one wh-cleft, one all-cleft, one relative clause each).
